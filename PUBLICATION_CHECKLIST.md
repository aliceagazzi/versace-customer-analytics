# Publication checklist

- [ ] Confirm that university/project partners and any data owner allow public release of the **code**.
- [ ] Confirm the correct authorship and describe your individual contributions.
- [ ] Review notebook source cells for secrets, proprietary business rules, internal links and confidential content.
- [ ] Do **not** upload the source CSVs, user identifiers, or intermediate Excel files without explicit authorization.
- [ ] Review licensing and any brand-use restrictions.
- [ ] If reproducibility is desired, create a synthetic or authorized sample dataset and adapt notebook paths.
- [ ] Re-run notebooks in a safe environment with permitted data; dependencies and results have not been independently validated.

The notebooks in this package have had saved outputs removed as a precaution. This does not certify that the source code itself is free of sensitive content.
